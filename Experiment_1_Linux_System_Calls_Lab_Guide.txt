EXPERIMENT 1 — BASIC SYSTEM CALLS IN LINUX
==========================================

AIM
---
Write a C program to demonstrate basic system calls in Linux.

IMPORTANT FOR LAB
-----------------
This guide assumes you may get a completely fresh Kali/Linux PC.
You do NOT need any previous experiment to have been performed.

PART A — CHECK GCC
------------------
1. Open Terminal.

2. Check whether GCC is installed:

   gcc --version

3. If "command not found" appears, install it:

   sudo apt update
   sudo apt install gcc -y

PART B — CREATE THE C PROGRAM
-----------------------------
1. Create/open the program:

   nano exp1.c

2. Paste the following code:

#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <fcntl.h>
#include <sys/types.h>
#include <sys/wait.h>

int main()
{
    int fd;
    pid_t pid;
    char buffer[100];

    printf("===== LINUX SYSTEM CALL DEMONSTRATION =====\n\n");

    // getpid() - returns process ID
    printf("Process ID (PID): %d\n", getpid());

    // getppid() - returns parent process ID
    printf("Parent Process ID (PPID): %d\n", getppid());

    // open() - create/open a file
    fd = open("demo.txt", O_CREAT | O_WRONLY | O_TRUNC, 0644);

    if (fd == -1)
    {
        perror("Error opening file");
        return 1;
    }

    printf("\nFile opened successfully.\n");

    // write() - write data into file
    char message[] = "Hello! This data is written using the write() system call.\n";

    write(fd, message, sizeof(message) - 1);

    printf("Data written successfully.\n");

    // close() - close the file
    close(fd);

    printf("File closed successfully.\n");

    // open file again for reading
    fd = open("demo.txt", O_RDONLY);

    if (fd == -1)
    {
        perror("Error opening file");
        return 1;
    }

    // read() - read data from file
    int bytes = read(fd, buffer, sizeof(buffer) - 1);

    if (bytes == -1)
    {
        perror("Error reading file");
        close(fd);
        return 1;
    }

    buffer[bytes] = '\0';

    printf("\nData read from file:\n");
    printf("%s", buffer);

    close(fd);

    // fork() - create a child process
    pid = fork();

    if (pid < 0)
    {
        perror("Fork failed");
        return 1;
    }
    else if (pid == 0)
    {
        // Child process
        printf("\nChild Process:\n");
        printf("Child PID  : %d\n", getpid());
        printf("Parent PID : %d\n", getppid());
    }
    else
    {
        // Parent process
        printf("\nParent Process:\n");
        printf("Parent PID : %d\n", getpid());
        printf("Child PID  : %d\n", pid);

        // wait() - wait for child process
        wait(NULL);

        printf("Child process completed.\n");
    }

    return 0;
}

3. Save and exit nano:

   Ctrl + O
   Enter
   Ctrl + X


PART C — COMPILE
----------------
Compile:

   gcc exp1.c -o exp1

If there is NO output/error, compilation was successful.


PART D — RUN
------------
Run:

   ./exp1

WHAT THE PROGRAM DEMONSTRATES
-----------------------------
getpid()
    Gets the Process ID of the currently running process.

getppid()
    Gets the Process ID of its parent process.

open()
    Opens or creates a file.
    demo.txt is created with permission 0644.

write()
    Writes data into the opened file.

read()
    Reads data from the file into a buffer.

close()
    Closes an open file descriptor.

fork()
    Creates a new child process.
    After fork(), both parent and child continue execution.

wait()
    Makes the parent wait until the child process finishes.


OPTIONAL VERIFICATION
---------------------
The program creates demo.txt. Check it with:

   ls -l demo.txt

View its contents:

   cat demo.txt

Expected text:

   Hello! This data is written using the write() system call.


0644 PERMISSION QUICK REMINDER
------------------------------
4 = read
2 = write
1 = execute

6 = 4 + 2 = read + write
4 = read
4 = read

Therefore:

0644 = rw-r--r--

Owner  : read + write
Group  : read only
Others : read only

COMMON ERRORS
-------------
1. gcc: command not found

   sudo apt update
   sudo apt install gcc -y


2. exp1.c: No such file or directory

   Check files:
   ls

   Make sure you saved the program as exp1.c.


3. ./exp1: No such file or directory

   Compile again:
   gcc exp1.c -o exp1

   Then:
   ./exp1


4. Compilation errors after copy/paste

   Reopen:
   nano exp1.c

   Check that the entire code was pasted correctly.


5. Parent/child output order looks slightly different

   This can happen because parent and child are separate processes and
   scheduling/output order can vary. Different PID numbers are also normal.
