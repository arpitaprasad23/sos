EXPERIMENT 6 — BANKER'S ALGORITHM (LAB-READY)

Aim:
Write a program to demonstrate deadlock avoidance using Banker's Algorithm.

IMPORTANT:
This version takes the matrices as INPUT. This is better for the practical because you can use whatever values the examiner gives you.

------------------------------------------------------------
STEP 1 — CREATE THE C FILE
------------------------------------------------------------

Open Terminal and type:

nano banker.c

Paste this program:

#include <stdio.h>

#define MAX_PROCESSES 10
#define MAX_RESOURCES 10

int main()
{
    int n, m;

    int allocation[MAX_PROCESSES][MAX_RESOURCES];
    int maximum[MAX_PROCESSES][MAX_RESOURCES];
    int need[MAX_PROCESSES][MAX_RESOURCES];
    int available[MAX_RESOURCES];

    int work[MAX_RESOURCES];
    int finish[MAX_PROCESSES] = {0};
    int safeSequence[MAX_PROCESSES];

    int count = 0;

    printf("===== BANKER'S ALGORITHM =====\n\n");

    printf("Enter number of processes: ");
    scanf("%d", &n);

    printf("Enter number of resource types: ");
    scanf("%d", &m);

    printf("\nEnter Allocation Matrix:\n");

    for (int i = 0; i < n; i++)
    {
        printf("P%d: ", i);

        for (int j = 0; j < m; j++)
            scanf("%d", &allocation[i][j]);
    }

    printf("\nEnter Maximum Matrix:\n");

    for (int i = 0; i < n; i++)
    {
        printf("P%d: ", i);

        for (int j = 0; j < m; j++)
            scanf("%d", &maximum[i][j]);
    }

    printf("\nEnter Available Resources:\n");

    for (int j = 0; j < m; j++)
        scanf("%d", &available[j]);

    // Need = Maximum - Allocation
    for (int i = 0; i < n; i++)
    {
        for (int j = 0; j < m; j++)
            need[i][j] = maximum[i][j] - allocation[i][j];
    }

    printf("\n===== NEED MATRIX =====\n");

    for (int i = 0; i < n; i++)
    {
        printf("P%d: ", i);

        for (int j = 0; j < m; j++)
            printf("%d ", need[i][j]);

        printf("\n");
    }

    // Work initially equals Available
    for (int j = 0; j < m; j++)
        work[j] = available[j];

    while (count < n)
    {
        int found = 0;

        for (int i = 0; i < n; i++)
        {
            if (finish[i] == 0)
            {
                int canExecute = 1;

                for (int j = 0; j < m; j++)
                {
                    if (need[i][j] > work[j])
                    {
                        canExecute = 0;
                        break;
                    }
                }

                if (canExecute)
                {
                    for (int j = 0; j < m; j++)
                        work[j] += allocation[i][j];

                    safeSequence[count] = i;
                    finish[i] = 1;
                    count++;
                    found = 1;
                }
            }
        }

        if (found == 0)
            break;
    }

    if (count == n)
    {
        printf("\n====================================\n");
        printf("SYSTEM IS IN A SAFE STATE\n");
        printf("====================================\n");

        printf("Safe Sequence: ");

        for (int i = 0; i < n; i++)
        {
            printf("P%d", safeSequence[i]);

            if (i != n - 1)
                printf(" -> ");
        }

        printf("\n");
    }
    else
    {
        printf("\n====================================\n");
        printf("SYSTEM IS NOT IN A SAFE STATE\n");
        printf("DEADLOCK MAY OCCUR\n");
        printf("====================================\n");
    }

    return 0;
}

------------------------------------------------------------
WHAT IS HAPPENING?
------------------------------------------------------------

Three important matrices/vectors:

Allocation = resources currently allocated to each process.

Maximum = maximum resources each process may require.

Available = resources currently free.

Need is calculated as:

Need = Maximum - Allocation

The algorithm checks whether a process has:

Need <= Work

Work initially equals Available.

If a process can finish, its allocated resources are released:

Work = Work + Allocation

The algorithm continues until either:

1. Every process can finish -> SAFE STATE

or

2. No unfinished process can proceed -> UNSAFE STATE
