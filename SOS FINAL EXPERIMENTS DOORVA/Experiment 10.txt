Auditd and journalctl 
- sudo systemctl status auditd
- if it's not installed then 
- sudo apt update
- sudo apt install auditd audispd-plugins
- sudo systemctl start auditd (2 times)
- sudo audsearch -ts today (today's audits)
- sudo aureport -au ( generates authentic report)
- sudo aureport -x (executed programs/commands)

2. Journctl
-   sudo journalctl --since today 
- for ssh events
- sudo journalctl -u ssh --since today
- for authentication messages
- sudo journalctl | grep -Ei "failed | failure | authentication|invalid|sudo"

Generate your audit report
Sudo ausearch -ts today > audit_report.txt
Sudo aureport -au >> audit_report.txt
Sudo aureport -x >> audit_report.txt
Sudo journalctl -u --since today >> audit_report.txt
